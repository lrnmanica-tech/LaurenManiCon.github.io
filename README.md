1) Título:
Viagens & Mundo

2) Sobre:
Este projeto possui origem no trabalho avaliativo da disciplina de Desenvolvimento Web do IFC, pelo professor Hewerton Oliveira.
O site apresenta-se como um blog de viagens, dando recomendações de países e localizações ao redor do mundo.
Tudo isto foi codificado e construído com o objetivo de aprender mais sobre o domínio das linguagens de HTML e CSS, assim como das plataformas GitHub e GitPages.

3) Tecnologias usadas:
HTML
CSS
Git
GitHub
GitHub Pages
